My short guide to Quickshell :)

Intro

Quickshell is a framework built on Qt/QML. With Quickshell, you can make basically any desktop widget you want - bars, lockscreens, wallpaper switchers, media players, full system settings menus, etc

Hello World


  import Quickshell
  import QtQuick

  PanelWindow {
    anchors {
      top: true
      left: true
      right: true
      }

    implicitHeight: 30

    Text {
      anchors.centerIn: parent
      text: "Hello world!"
    }
  }
